Features

Everything a VNC viewer should have done from the start

Built on top of TigerVNC, KZLauncher adds the small things that make daily use painless.

⛶

True F11 fullscreen

Toggle real borderless fullscreen at any time, independent of the VNC viewer's own UI.

⏻

Closes itself automatically

When your Pi shuts down, KZLauncher detects it and closes the viewer for you.

⚙

Settings, not config files

Viewer path, ping interval, fail threshold and hotkey — all editable from the app.

◐

Dark and light themes

Switch anytime from the Settings screen.

🛡

Validated, safe input

IP and hostname fields are checked before anything is passed to the system.

◇

Free and open source

MIT licensed. No accounts, no subscriptions, no paywalled features.

Getting started

Up and running in four steps

Install TigerVNC Viewer

Free and open source — no account needed.

Enter your Pi's IP address

Find it on the Pi by running "hostname -I". KZLauncher remembers it next time.

Press F11 for fullscreen

Toggle it on or off at any time during your session.

Turn off the Pi when you're done

KZLauncher notices and closes the viewer automatically — nothing to clean up.

Coming later: extensions with .KZLmod

A planned plugin format so the community can extend KZLauncher without touching the core app. Not available yet — follow the GitHub repo to hear when it lands.
